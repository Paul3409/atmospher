# Wetterkarten Studio

Installierbare Debug-APK des Android-Prototyps.

- Datei: `Wetterkarten-Studio-debug.apk`
- Version: 0.1.0
- Die App benötigt eine Internetverbindung für Satellitenkarten und Kartenbeschriftungen.
- Diese Debug-Version ist zum Ausprobieren gedacht; Kreisgrenzen, 3D-Höhendaten und Kartenexport sind noch nicht enthalten.

Auf Android die APK herunterladen und öffnen. Falls Android nachfragt, die Installation aus dieser Quelle erlauben.
